How should search metadata be written?

Use the subject category, component name, short description, and keywords so external scripts can discover the desired block quickly.

Why include light and dark mode in a reference file?

Because many copied snippets fail when theme surfaces change. Showing both modes makes the harvested block safer to reuse.

Why add Persian and RTL examples?

Typography, spacing, and alignment often break in RTL layouts. Dedicated specimens reduce integration surprises.
